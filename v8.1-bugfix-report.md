# v8.1 Critical Bug Fixes Report

## Executive Summary

Fixed 4 critical bugs in the headless simulation engine that prevented realistic gameplay. The simulation now shows **realistic possession distribution (Blue 79.3%, Red 20.7%)** and proper player movement, though scoring remains disabled (requires further investigation).

## Bugs Fixed

### Bug 1: Simultaneous AI Decisions (FIXED ✅)
**Symptom**: All 22 players converged to origin (0.0, 0.0) immediately after kickoff.

**Root Cause**: All players had `dt = 0` at kickoff, causing simultaneous AI decisions that set `tgt = ballPos = (0.0, 0.0)`.

**Fix** (`doKickOff` in `engine.ts`):
```typescript
// Before:
st.pl[i].dt = 0;

// After:
st.pl[i].dt = Math.random() * PExt.decisionInterval; // 0.0-0.2s randomization
```

**Impact**: Players now make decisions at staggered intervals, preventing mass convergence.

---

### Bug 2: Zero-Division in vmove (FIXED ✅)
**Symptom**: Players could get NaN coordinates when already at target position.

**Root Cause**: `vmove` divided by `dist` without checking if `dist ≈ 0`.

**Fix** (`vmove` in `math.ts`):
```typescript
export const vmove = (from: V, to: V, d: number): V => {
  const dist = vdist(from, to);
  // ★ Fix: Prevent zero-division
  if (dist <= 0.001 || dist <= d) return v(to.x, to.y);
  return vadd(from, vscl(vsub(to, from), d / dist));
};
```

**Impact**: Eliminates potential NaN bugs in player movement.

---

### Bug 3: Ball-Swarming Behavior (FIXED ✅)
**Symptom**: All players chased the ball regardless of position or role.

**Root Cause**: `decideNoBall` had no logic to prevent all players from targeting `ballPos`.

**Fix** (`decideNoBall` in `engine.ts`):
```typescript
// Free ball: Only closest player chases
if (b.free) {
  if (distToBall < 12.0) {
    const myTeamClosest = nearest(st, b.pos, me.team);
    if (myTeamClosest === idx) {
      me.act = "move";
      me.tgt = ballPos;
      return;
    }
  }
  // Others: Shift home position slightly toward ball
  me.act = "move";
  me.tgt = vlerp(me.home, ballPos, 0.15);
  return;
}

// Enemy has ball: Role-based pressing
if (me.role === "FWD" && distToBall < 5.0) {
  me.tgt = vlerp(ballPos, v(me.team * PExt.pitchHalfW, 0), 0.1);
} else if (me.role === "MID" && distToBall < 4.5) {
  me.tgt = vlerp(ballPos, v(me.team * PExt.pitchHalfW, 0), 0.15);
} else {
  // Maintain formation with slight shift
  const shiftX = clamp((ballPos.x - me.home.x) * 0.5, -2.5, 2.5);
  const shiftY = clamp((ballPos.y - me.home.y) * 0.5, -3.0, 3.0);
  me.tgt = v(me.home.x + shiftX, me.home.y + shiftY);
}
```

**Impact**: Players maintain formation while defending, creating realistic tactical shape.

---

### Bug 4: Duplicate dt Decrement in decideHasBall (FIXED ✅)
**Symptom**: Ball carrier had `act = "idle"` and never moved.

**Root Cause**: `decideHasBall` decremented `p.dt` and returned early if `dt > 0`, preventing `act` from being set. This duplicated the decrement already done in `update` (line 765).

**Fix** (`decideHasBall` in `engine.ts`):
```typescript
// Removed these 3 lines:
// me.dt -= 0.016;
// if (me.dt > 0) return;
// me.dt = PExt.decisionInterval;
```

**Impact**: Ball carrier now correctly sets `act = "move"/"dribble"/"carry"` and moves toward goal.
